# agents/

Agentes e integraciones de IA del laboratorio (asistentes, automatizaciones, workflows sobre APIs de LLM).

Alimenta desde Molino: router multi-proveedor, sanitización de PII, cost tracking y fallback offline (`~/Projects/molino/lib/ai/**`).

Se incorpora **por demanda**, cuando hay un problema concreto que un agente resuelve.
