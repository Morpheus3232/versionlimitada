# apps/

Apps y productos web del laboratorio. Cada app vive en su propia carpeta y, en general, en su **propio repo/deploy** (ver regla de independencia de marca/dominio).

Se puebla **por demanda**: solo cuando hay un proyecto validado. No creamos apps vacías "por si acaso".

## Cómo nace una app

PROBLEMA → investigación → hipótesis → prototipo → MVP → usuarios → pago → retención → iterar/escalar/descartar.

Cuando una app necesita lo mismo que otras dos, se extrae a `../shared/` (no antes).
